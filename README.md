# Physics X Lab
### (or The Great Atom Debate Lab)

An interactive educational lab dedicated to the historical figures and debates that shaped modern physics — built in the spirit of Buckminster Fuller’s *Synergetics* educator tools, but centered on the people and stories Paul Halpern writes and tweets about.

**Live site:** https://qsolkcb.github.io/phalpern/

Zero-build • Offline-first • Pure HTML/CSS/JS • MPL-2.0

Inspired by Feynman’s “Physics X” course and *The Great Atom Debate*.
